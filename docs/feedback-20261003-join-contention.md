계약 범위 판정

운영 웹에 반영한 수정
자동 중단 주문 복구 작업이 즉시 반복 재시도하면서 고객의 새 참여 작업을 기다리게 하는 문제를 줄였습니다. 백그라운드 읽기 재시도는 대기 시간을 요청 큐 밖에서 보내므로 참여·입금 변경 요청이 먼저 처리될 수 있습니다.
참여 재시도는 같은 요청 ID·권한·수량을 유지합니다. 실패를 성공으로 처리하지 않으며, 재시도가 끝났을 때 자동 재시도 중이라는 잘못된 안내를 하지 않습니다. 입력한 참여 정보는 유지합니다.
내 주문의 그룹 채팅 버튼으로 기존 채팅에 바로 들어가며, 다시 참여시키는 경로가 없는지 검사했습니다.
입금 상태 변경의 서버 응답이 늦게 도착하고 그 전에 채팅에서 나갔을 때, 같은 로그인 사용자에게는 확인된 결과를 보존하도록 수정했습니다. 다른 사용자로 바뀐 경우 이전 사용자의 결과를 저장하지 않습니다. 이 오류는 수정 전 Chromium과 WebKit에서 재현했고 수정 후 검사에서 통과했습니다.
확인번호 등록과 이전 주문 복구의 안내를 구분했습니다. 다른 기기에서 임의의 새 번호를 등록하거나 같은 전화번호로 로그인하는 것만으로 과거 주문이 연결되지 않는다는 점을 명시했습니다. 등록할 권한이 없는 경우 새 주문을 하라고 안내하지 않습니다.

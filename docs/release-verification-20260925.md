## 판정

웹 배포와 Apps Script 배포는 별도이다. 아래 중앙 처리 수정은 새 Apps Script 버전 배포와 운영 재검증 전까지 완료로 간주하지 않는다. 고객 최종 검수·인수 승인 역시 아직 확인하지 않았다.

## 수정

- 열린 그룹방을 알림에서 중복 조회하지 않는다. 스냅샷 읽기는 즉시 여러 번 재시도하지 않고 다음 폴링으로 재시도한다. 저장 요청의 중복 방지·재시도는 유지한다.
- 일시적인 알림 조회 실패가 기존 미확인 숫자를 0으로 지우지 않는다. 서버 오류 때 조회 간격을 10/20/40/60초로 늘리고 성공 후 5초로 복귀한다.
- 창 활성화 이벤트가 진행 중인 채팅 조회를 취소하고 다시 시작하지 않는다.
- 계약 A-03에 따라 잠금 중 호스트·참여자의 전송을 차단하고 관리자만 작성·잠금 해제를 허용한다. 화면과 중앙 권한 검증 양쪽을 수정했다.
- 프로필 이벤트 처리는 방문자 열을 정확히 검색하고 해당 행의 빈 필드만 채운다. 기존 셀·다른 사용자·전화번호의 앞자리 0을 보존한다. 기존 기록의 재가공이나 일괄 복구 작업은 실행하지 않는다.
- 필요한 시트를 동시에 만들 때 다른 요청이 먼저 생성한 시트를 다시 읽는다.
- 집계 캐시는 30초간 사용한다. 분석 이벤트마다 전체 집계 캐시를 지우지 않아 반복 전체 조회를 줄인다. 거래·입금 상태 캐시와는 별개이다.
- collector 배포 도구는 미커밋 코드 또는 origin/main에 없는 커밋을 원격 호출 전에 거부한다. 실행 계정 변경 방지 규칙은 유지한다.

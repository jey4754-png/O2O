## 검수 대상과 확인 방법

그룹 채팅, 관리자 잠금, 미확인 배지, 그룹 거래 상태, 참여자 입금 상태·이력, 목표 인원, 예상금액 계산기, 11개 카테고리, 공유·딥링크, 행동 데이터와 소스 인수를 확인합니다. 기존 피드백 상품은 탐사 메모지, 동원 참치, 퍼실, 맥주입니다.

갑이 제공한 테스트 그룹과 테스트 데이터를 사용합니다. 다른 두 기기 또는 브라우저에서 각각 기존 테스트 프로필로 접속하고, 호스트·참여자·관리자 역할을 구분해 확인합니다. 관리자 PIN과 원래 브라우저의 관리키는 일반 채팅으로 전달하지 않습니다. 실제 고객의 거래를 검수 목적으로 바꾸지 않습니다.

모바일 브라우저에서 공유 시트를 지원하지 않으면 링크 복사로 대체합니다. 앱 화면을 열어 둔 상태의 약 5초 갱신을 확인하며, 앱 종료 푸시나 WebSocket의 즉시 수신을 검수 기준으로 삼지 않습니다. 화면 표시명인 모집 중/주문 확인/준비 완료/픽업 완료는 계약의 모집 중/모집 완료/상품 구매 완료/전달 완료에 대응합니다.

## 이미 준비한 근거

9월25일 기능 수정의 단위·API·Apps Script636건과 Chromium·WebKit200건이 통과했습니다. 이후 집계 조회 대기시간 한정 수정은 관련41건으로 검증했습니다. 합성 데이터 자동검증이며 실기기 최종 검수 결과를 대신하지 않습니다.

9월26일 중앙 데이터 내보내기는12개 시트이며, 활성 주문45건의 입금 저장 상태가 참여자 기록과 모두 일치했습니다. 백업 무결성과 집계대상 이벤트15,468건의 API·원본 일치도 확인했습니다. 이는 해당 시점 저장값 대조이며 모든 사용자의 화면 동작 또는 과거 오류 사례의 종료 판정을 뜻하지 않습니다.

상세 근거는 `release-verification-20260925.md`, `closeout-verification-20260926.md` 및 `acceptance-preparation-20260928.md`에 구분해 기록했습니다.

## 주요 변경내역

- 그룹 채팅, 5초 갱신, 최신 100건, 재접속 기록, 관리자 잠금과 미확인 배지를 구현·회귀검증했다.
- 그룹 4단계 상태, 참여자 입금 상태, 한 단계 복구, 중앙 변경 이력, 목표 인원 규칙, 예상금액 계산기, 11개 카테고리를 일관되게 연결했다.
- 공유 URL·모바일 공유 시트·프로필 확인 뒤 딥링크와 합의된 행동 이벤트를 반영했다.
- 중앙 요청의 지연·응답 유실·중복 클릭·재시도에서 같은 작업이 중복 반영되지 않도록 보완했다.
- 중앙 주문을 먼저 조회한 뒤 아직 전송되지 않은 주문만 게시하도록 바꿨다. 다른 화면에서 이미 입금완료된 주문의 오래된 로컬 사본을 다시 전송해 충돌·시간초과를 만들던 경로를 차단했다.
- 전화번호 표시 형식 차이로 같은 주문을 다른 주문처럼 판단하던 문제와, 늦게 끝난 과거 요청이 최신 입금 상태를 삭제·복구하는 경쟁 조건을 수정했다.
- 내 주문은 중앙의 최신 입금 상태를 유지하며, 읽기 새로고침마다 전체 이력을 중복 조회하지 않도록 요청량을 줄였다.
- 그룹 채팅은 응답 완료 후 5초를 더 기다리는 방식에서 요청 시작 간격 약 5초로 바꿨고, 새 메시지 배지는 5초마다 그룹별 읽기를 병렬 처리한다.
- 중앙 주문과 완료 예약이 정확히 일치하는 기존 고객 그룹만 안전하게 다시 연결하도록 복구 경로를 추가했다. 근거가 없거나 모순되는 데이터는 임의 생성하지 않고 점검 안내를 유지한다.

## 환경·외부 서비스 인수

운영에 필요한 환경변수 이름은 아래와 같다. 값은 이 문서와 GitHub에 기록하지 않는다.

- Vercel/서버: `GOOGLE_SHEETS_COLLECTOR_URL`, `GOOGLE_SHEETS_COLLECTOR_TOKEN`, `O2O_UPSTREAM_TIMEOUT_MS`, `O2O_ADMIN_PIN`, `O2O_CAPABILITY_SECRET`, `O2O_RELEASE_PHASE`
- 선택 데이터 API: `O2O_DATA_API_ORIGIN`, `O2O_DATA_API_TOKEN`, `O2O_ALLOWED_ORIGINS`
- 브라우저 빌드/분석: `VITE_POSTHOG_KEY`, `VITE_POSTHOG_HOST`, `VITE_RELEASE_PHASE`, `VITE_ENABLE_GROUP_LOCAL_FALLBACK`
- 외부 서비스: Vercel, Google Apps Script/Sheets, PostHog, GitHub
- 주요 런타임 의존성: React, Vite, PostHog JS, Lucide React, QRCode. 라이선스와 권리는 각 프로젝트 약관에 따른다.

Vercel Production에는 필수 환경변수 이름이 등록된 것을 확인했다. 실제 비밀값 전달·교체와 각 서비스의 소유·관리 권한은 인수자가 로그인한 상태에서 직접 확인한다. Apps Script 프로젝트는 `Joo Joo` 소유, `dev@bottlecorp.kr` 편집기로 기록되어 있다. 잔금 수령 후 권한 인계 시점은 계약 초안 제8조에 따른다.
